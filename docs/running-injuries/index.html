이럴 때는 달리기를 멈추고 진료를

  • 뼈 위의 한 점이 아프고, 걷거나 쉴 때와 밤에도 아플 때
  • 관절이 붓거나, 걸리고 잠기는 느낌이 있을 때
  • '뚝' 하는 느낌 뒤에 힘이 들어가지 않거나 체중을 싣지 못할 때
  • 저리거나 감각이 둔해질 때
  • 2~3주 양을 줄여도 나아지지 않을 때

달려도 되는 통증, 멈춰야 하는 통증

  • 달리는 중 통증이 가볍고(10점 만점에 3점 안팎까지) 다음 날 아침이면 가라앉는다면, 양을 줄여 이어 가도 되는 경우가 많습니다.
  • 달릴수록 심해지거나 걸음걸이가 달라질 정도라면 그날은 멈춥니다.
  • 복귀할 때는 한 번에 달리는 거리부터 조금씩 늘리고, 빠른 훈련은 맨 나중에 되돌립니다.
