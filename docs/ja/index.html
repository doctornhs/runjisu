結果の読み方

  • ランジスは最大酸素摂取量（VO2max）と単位は同じですが、ランニングエコノミーも含んだ値です。市民ランナーは実験室の測定値より低く出ることが多く、ハーフやフルの記録から求めるとさらに低くなります。
  • 予想タイムは、その距離を同じレベルで準備した場合の値です。10Kの記録だけから見たフルの予想は、ロング走が不足していると実際より速く出ます。
  • トレーニングペースは今の実力が基準です。目標タイムではなく最近の記録を入れてください。

ランニングの先へ

時計の心拍はどの強度？年齢または最大心拍から、強度別の心拍範囲を計算します。心拍ゾーン → あなたの体力は何歳？レース記録がなくても、12分間走か1.6kmウォークでわかります。体力年齢 → トレッドミル時速10kmはキロ何分？速度、ペース、距離別の完走タイムを相互に換算します。ペース換算 → LSD、ビルドアップ、ネガティブスプリット走り始めると出会う聞き慣れない言葉を、やさしく解説しました。ランニング用語 → 製品より先にタイプをどんなランナーにどんなシューズや道具が合うかをまとめました。ギアガイド → この数字の根拠は？計算式、参考にした研究、よくある質問をまとめました。根拠・FAQ →
