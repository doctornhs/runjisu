今回のロング走、
どこまで延ばせる？

ランナー5,205人を18か月追跡した研究では、ケガは週間距離より1回に走った距離とよりはっきり結びついていました。直近30日の最長距離より10%以上長く走った日に、使いすぎによるケガが増えました。

同じ研究で、週ごとの増加率はケガとはっきりした関連がありませんでした。よく言われる「週10%ルール」は経験則なので、参考程度に見てください。

距離より痛みが優先の場合

  • すね、足の甲、かかとの骨の一点を押すと痛い
  • 走るほど悪化する、または休養日や夜にも痛む
  • 腫れている、歩くと足を引きずる

一つでも当てはまれば走るのをやめて受診してください。疲労骨折のような問題は、早く休むほど早く治ります。

走った日を記録すれば、最長距離と週間距離を別々に数える必要がありませんランニング記録 →

根拠：Schuster Brandt Frandsen J ほか、British Journal of Sports Medicine、2025;59(17):1203-1210。観察研究で、ケガは参加者の自己申告です。倍率はハザード比（HRR）で、10%以下の範囲と比べた値です。
