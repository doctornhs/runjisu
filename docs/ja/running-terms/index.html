ランニング用語辞典

走り始めると出会う聞き慣れない言葉を、やさしく解説しました。調べたい用語を入れるとすぐに絞り込みます。

該当する用語がありません。別の言葉で探してみてください。

記録と大会

PB · PRPersonal Best · Personal Record
自己最高記録のこと。記録を更新したときに「PBを出した」と言います。
サブ3・サブ4Sub-3 · Sub-4
フルマラソンを3時間、4時間以内で完走することです。サブ4は3時間59分59秒までを指します。ハーフや10kmにも同じように使います。 目標別ペース表 →
ネットタイム・グロスタイム
グロスタイムはスタートの号砲から、ネットタイムは自分がスタートラインを踏んだ瞬間からゴールまでを計った記録です。後方のブロックからスタートすると、両者が数分ずつ違います。実力を見るときはネットタイムを使います。
ゼッケンBIB
胸につける番号札です。計測チップが裏に付いていることが多いので、折ったりくしゃくしゃにしたりしないでください。
DNS · DNF
DNSは申し込んだのにスタートしなかったこと（Did Not Start）、DNFはスタートしたが完走できなかったこと（Did Not Finish）です。
関門・制限時間
大会が定めた制限時間です。フルは大会によって5〜6時間前後で、区間ごとに通過制限時間を設けることもあります。大会要項で確認します。
ペーサーPacemaker
目標タイムに合わせて一定のペースで走ってくれるランナーです。目標タイムを書いた風船や旗をつけて走ります。
イーブンペース
最初から最後まで同じ速さで走ることです。 区間表をつくる →
ネガティブスプリット
後半を前半より速く走ることです。逆に後半が遅くなるとポジティブスプリットと言います。
30kmの壁
フルマラソンの30km前後で、急に脚が重くなりペースが落ちる現象です。体に蓄えた炭水化物が尽きることが主な原因とされます。
テーパリングTapering
レース前の1〜3週間、練習量を減らして疲労を抜く期間です。
カーボローディング
レース前の2〜3日間、炭水化物を多めにとって筋肉の燃料を満たすことです。

トレーニング

ペース
1kmを走るのにかかる時間です。5分30秒のペースは5:30/kmと書きます。 ペース換算 →
イージーランEasy run
隣の人と会話できる楽な速さのランニングです。1週間のランニングの大部分を占めます。 自分のイージーペースを計算 →
リカバリーラン
きつい練習やレースの翌日に、疲れを取るためにごく軽く短く走ることです。
LSDLong Slow Distance
ゆっくりした速さで長く走るロング走です。週末のロング走をよくこう呼びます。
ペース走
決めた速さで休まず続けて走る練習です。
テンポ走・閾値走Tempo run
「楽にきつい」速さで20分前後続けて走る練習です。速いペースを長く保つ力を養います。
インターバルInterval
速く走ることと休むことを交互に繰り返す練習です。たとえば1kmを速く走って2〜3分休むことを5回繰り返します。
ビルドアップ走
ゆっくり始めて、区間ごとに少しずつ速度を上げていくランニングです。
ファルトレクFartlek
スウェーデン語で「スピード遊び」。決まった枠なしに速い・遅いを混ぜて走ります。
流し（ウィンドスプリント）Strides
80〜100mを15〜20秒ほど、速いけれど力を抜いて走る短い加速走です。イージーランの最後に数本加えます。
ウォームアップ・クールダウン
メインの練習の前後に軽く走って、体を温めたり冷ましたりすることです。
クロストレーニング
自転車や水泳のように、ランニング以外の運動で体力を養うことです。ケガで休むときに体力を保つのに使います。
週間走行距離
1週間に走った距離の合計です。マイレージとも言います。 週間メニュー →
ケイデンスCadence
1分間の歩数（ピッチ）です。時計にはspmで表示されます。

体と体力

VO2max
最大酸素摂取量です。運動中に体が1分間に使える酸素の最大量で、有酸素体力を表す代表的な指標です。 自分の体力年齢 →
ランジス
レース記録から逆算した有酸素能力の指数です。記録一つでトレーニングペースと他の距離の予想タイムを求めるのに使います。 自分のランジスを計算 →
乳酸閾値
運動強度を上げていくと、疲労物質が急にたまり始めるポイントです。この付近の速さが閾値ペースです。
ランニングエコノミー
同じ速さをどれだけ少ないエネルギーで走れるかを表す効率です。VO2maxが同じでも、この効率がよければ記録はより速くなります。
最大心拍数・心拍ゾーン
最大心拍数は心臓が1分間に打てる最大の回数で、心拍ゾーンはその何%かで運動強度を分けた区間です。 心拍ゾーンを計算 →
グリコーゲン
筋肉と肝臓に蓄えられた炭水化物です。ランニングの主な燃料です。
遅発性筋肉痛DOMS
運動して1〜2日後に現れる筋肉痛です。下り坂を走った後や、いつもより強く運動した後にひどくなります。
使いすぎによるケガ（オーバーユース障害）
一度の事故ではなく、繰り返しの負荷が積み重なって起こるケガです。ランニング障害の大部分がこれに当たります。 ランニング障害ガイド →
ランナーズハイ
長く走っているときに訪れる、気持ちよく軽やかな状態のことです。

ギア

ドロップ（オフセット）
シューズのかかととつま先の高さの差です。mmで表し、オフセットとも言います。
スタックハイト
足裏の下にあるソールの厚さです。
カーボンシューズ
カーボンファイバーのプレートと反発性の高いフォームを入れたレーシングシューズです。厚底シューズとも呼ばれます。 ランニングシューズのタイプ →
安定性シューズ
着地のときに足が内側に倒れすぎるのを抑える構造が入ったシューズです。
回内（プロネーション）Pronation
着地のときに足が内側に少し転がる自然な動きです。プロネーションとも言います。
エナジージェル
走りながらとる炭水化物の補給食です。主にハーフ以上の距離で使います。
