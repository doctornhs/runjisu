記録をトレーニングへ

今週の練習メニューをつくる週間走行距離と走る日数に合わせて、曜日ごとの練習とペースを決めます。週間メニュー → サブ4はキロ何分？フル、ハーフ、10km、5kmの目標タイム別ペースとトレッドミル速度を一つの表にまとめました。目標ペース表 → 目標タイム、各区間を何分で通過する？5kmごとの通過タイムを出し、目標が今の実力に合っているか確かめます。レース計画 → 今週末はどこで走る？韓国の大会を種目と地域で探し、ソウル・春川・JTBCのエントリー時期も確認できます。大会日程 → クラブのグループ走、ペースをどう分ける？メンバーの記録を貼り付けると、実力の近い人どうしでグループを分け、グループごとのイージーペースを決めます。クラブのペース分け → 走った日を記録すれば週間距離、30日最長距離、シューズの累積距離が自動で計算されます。ランニング記録 →

ケガなく長く

走ると痛いのはここ？ひざ、すね、足、太もも。よくあるランニング障害の症状と対処、受診が必要なサインをまとめました。ランニング障害 → 今回のロング走、どこまで延ばせる？直近30日の最長距離と比べ、ケガが増える範囲をお知らせします。距離急増チェック → そのシューズ、何km走った？シューズごとに累積距離を記録し、交換時期を確認します。シューズ交換 →

ランニングの先へ

時計の心拍はどの強度？年齢または最大心拍から、強度別の心拍範囲を計算します。心拍ゾーン → あなたの体力は何歳？レース記録がなくても、12分間走か1.6kmウォークでわかります。体力年齢 → トレッドミル時速10kmはキロ何分？速度、ペース、距離別の完走タイムを相互に換算します。ペース換算 → LSD、ビルドアップ、ネガティブスプリット走り始めると出会う聞き慣れない言葉を、やさしく解説しました。ランニング用語 → 製品より先にタイプをどんなランナーにどんなシューズや道具が合うかをまとめました。ギアガイド → この数字の根拠は？計算式、参考にした研究、よくある質問をまとめました。根拠・FAQ →
