膝蓋大腿疼痛症候群

痛む場所・ひざの前側、膝蓋骨（ひざのお皿）のまわり · 別名 ランナーズニー

膝蓋骨のまわりや裏側が重だるく痛む、ランナーに最も多いひざの痛みです。膝蓋骨と大腿骨が接する関節に、耐えきれない負荷が繰り返しかかると起こります。

こんな感じなら

  • ひざの前が広く重だるく、正確に一点を指すのは難しい痛みです。
  • 階段の上り下り、しゃがむ動作、下り坂のランニングで悪化します。
  • 映画館や車内のように、ひざを曲げて長く座った後に立ち上がると痛みます。

なぜ起こるのか

  • 走る距離や回数を急に増やしたときによく起こります。
  • 太ももの前の筋肉とお尻の筋肉が弱いと、膝蓋骨の関節にかかる負担が大きくなります。
  • 下り坂、階段、深いスクワットはこの関節にかかる圧力が大きい動作です。

自分でできること

  • 痛みを招く動作（下り坂、階段の繰り返し、深くしゃがむ）を減らし、平地中心で走ります。
  • 走っている間の痛みが軽いレベルを超えたら、その日は減らします。
  • 太ももの前とお尻の筋力トレーニングを、痛みのない範囲で続けます。
  • 歩幅を少し狭めて歩数（ピッチ）を増やすと、ひざの負担が減ることが多いです。

こんなときは受診を

  • ひざが目に見えて腫れる、熱をもつ
  • ひざが急にガクッと折れる、伸びずに引っかかる感じがある
  • ひねったり転んだりしてから痛む、または4週間以上調整しても変わらない

この案内は一般的な情報であり、診断に代わるものではありません。同じ場所の痛みでも原因が異なることがあるので、症状がはっきりしているときや長引くときは受診してください。
