足首の捻挫

痛む場所・足首の外側 · 別名 足首のひねり

でこぼこ道や段差で足首が内側に折れ、外側の靭帯を痛める障害です。よくあるからと軽く済ませると何度もひねる足首になりやすいため、痛みが治まった後のバランストレーニングが大切です。

こんな感じなら

  • ひねった直後に、外くるぶしの前と下が腫れて痛みます。
  • 1〜2日のうちにあざができることもあります。
  • 体重をかけると痛み、足首が不安定に感じます。

なぜ起こるのか

  • トレイル、歩道の段差、暗い道で足を踏み外したときに起こります。
  • 以前にひねった足首はバランス感覚が落ちていて、再びひねりやすくなります。
  • 疲れがたまったランニングの後半によく起こります。

自分でできること

  • 最初の数日は無理をせず、腫れがひどければ圧迫して脚を高くしておきます。
  • 痛みの許す範囲で早めに足首を動かし、体重をかけることが回復に役立ちます。
  • 片脚立ちのようなバランストレーニングを、痛みが治まった後も数週間続けます。再びひねることを減らしてくれます。
  • 片脚でのつま先立ちとその場ジャンプが痛くなければ、平地から走り始めます。

こんなときは受診を

  • ケガの直後も、時間がたってからも4歩歩けない
  • くるぶしの後ろの縁や、足の外側中央の骨を押すと痛む（骨折の確認が必要です）
  • 腫れや不安定な感じが数週間たっても残る

この案内は一般的な情報であり、診断に代わるものではありません。同じ場所の痛みでも原因が異なることがあるので、症状がはっきりしているときや長引くときは受診してください。
