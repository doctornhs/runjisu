アキレス腱症

痛む場所・かかとの上のアキレス腱 · 別名 アキレス腱炎

かかとの上のアキレス腱がこわばって痛む障害です。腱が繰り返しの負荷に耐えきれずに起こる変化なので、休むだけより、適切な負荷で腱を鍛え直すことが治療の中心です。

こんな感じなら

  • 朝の一歩目や、長く座った後に立ち上がるときにアキレス腱がこわばります。
  • 走り始めは痛く、体が温まると和らぎ、翌朝またこわばります。
  • かかとの骨から指2〜3本分上が厚ぼったくなったり、押すと痛んだりします。

なぜ起こるのか

  • インターバル、坂道、流しのような速い練習を急に増やしたときによく起こります。
  • ふくらはぎの筋力が足りないと、腱にかかる負担が大きくなります。
  • ドロップの小さいシューズに急に替えたことがきっかけになることもあります。

自分でできること

  • 速い練習と坂道を先に外し、平地を楽な速さでだけ走ります。
  • 階段の縁でかかとをゆっくり上げ下げするふくらはぎの運動を続けます。効果が出るまでふつう3か月近く続ける必要があります。
  • 運動中の痛みが軽く、翌朝のこわばりが悪化しない範囲で負荷を上げます。
  • 完全に休むだけだと腱が弱くなり、復帰が遅れることがあります。

こんなときは受診を

  • 「ブチッ」という感覚とともに急に痛み、つま先立ちができない（断裂の可能性があり、すぐに受診が必要です）
  • 腱が目に見えて腫れる、赤くなる、熱をもつ
  • 6〜8週間運動しても良くならない

この案内は一般的な情報であり、診断に代わるものではありません。同じ場所の痛みでも原因が異なることがあるので、症状がはっきりしているときや長引くときは受診してください。
