ランニング障害ガイド

ランナーのケガの多くは、転倒ではなく繰り返しの負荷が積み重なって起こります。痛む場所からよくある障害を探し、自分で調整できることと受診が必要なサインを見分けましょう。

こんなときは走るのをやめて受診を

  • 骨の上の一点が痛み、歩くときや安静時、夜間も痛む
  • 関節が腫れる、引っかかる・ロックする感じがある
  • 「ポキッ」という感覚の後に力が入らない、体重をかけられない
  • しびれや感覚の鈍さがある
  • 2〜3週間量を減らしても良くならない

走ってもいい痛み、やめるべき痛み

  • 走っている間の痛みが軽く（10点満点で3点前後まで）、翌朝には治まるなら、量を減らして続けてよいことが多いです。
  • 走るほど悪化したり、歩き方が変わるほどならその日はやめます。
  • 復帰するときは1回に走る距離から少しずつ増やし、速い練習は最後に戻します。
