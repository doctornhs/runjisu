ハムストリングの肉離れ

痛む場所・太ももの裏 · 別名 太もも裏の筋肉の損傷

速く走っているときに太ももの裏が急にピリッとする筋肉の損傷です。長距離ランナーでは、急な損傷より、お尻のすぐ下がじわじわ重だるくなる腱の問題として現れることも多くあります。

こんな感じなら

  • 流しやインターバルの最中に、太ももの裏が急にピリッとしたり張ったりします。
  • 脚を前に伸ばしたり腰を曲げたりすると、太ももの裏が張って痛みます。
  • 長く座ったときや速く走るときにお尻の下の奥が重だるいなら、腱の問題かもしれません。

なぜ起こるのか

  • ウォームアップなしで速く走ると起こりやすくなります。
  • 疲れがたまった状態でのスピード練習がよくあるきっかけです。
  • 一度痛めたハムストリングは再び痛めやすくなります。

自分でできること

  • ピリッときた日は、速いランニングをすぐにやめます。
  • 最初の数日は痛くない範囲で歩き、痛みを我慢して強く伸ばすストレッチは避けます。
  • 痛みが治まったら、ブリッジのような筋力トレーニングを軽く始めて強度を上げます。
  • 楽に走っても痛くなくなるまで、流しとインターバルは延期します。

こんなときは受診を

  • 「ブチッ」という感覚があった、または太ももの裏に広くあざができた
  • 歩くのが難しい、脚に力が入らない
  • お尻の下の痛みが1か月以上続く

この案内は一般的な情報であり、診断に代わるものではありません。同じ場所の痛みでも原因が異なることがあるので、症状がはっきりしているときや長引くときは受診してください。
