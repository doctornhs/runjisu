腸脛靭帯炎

痛む場所・ひざの外側 · 別名 ランナー膝（ITバンド症候群）

走っていると一定の距離からひざの外側が鋭く痛んでくる障害です。太ももの外側を下りてくる腸脛靭帯が、ひざの外側の骨の出っ張り付近で繰り返し刺激されて起こります。

こんな感じなら

  • 走り始めて一定の距離や時間がたつと、ひざの外側が刺すように痛みます。
  • 下り坂や階段を下りるときに悪化します。
  • 休むと治まりますが、また走ると同じあたりで再び痛みます。
  • ひざの外側の骨の出っ張りを押すと痛みます。

なぜ起こるのか

  • 週間距離やロング走を急に増やしたときによく起こります。
  • 下り坂のランニング、片側に傾いた道路の端、トラックを一方向にだけ回る練習が負担を大きくします。
  • お尻の外側の筋肉が弱いと、ひざが内側に倒れて腸脛靭帯にかかる張力が大きくなります。

自分でできること

  • 痛みが出る前の距離までだけ走り、下り坂と階段の練習はしばらく外します。
  • 自転車や水泳のように痛くない運動で体力を保ちます。
  • 横向きに寝て脚を上げる運動、バンドをかけた横歩きなど、お尻の外側の筋肉を鍛える運動を続けます。
  • 歩行や階段が痛くなくなったら、平地で短く始めて少しずつ延ばします。

こんなときは受診を

  • 2〜3週間量を減らしても良くならない
  • ひざが腫れる、引っかかる・ロックする感じがある
  • 歩くだけで痛い、または夜も痛む

この案内は一般的な情報であり、診断に代わるものではありません。同じ場所の痛みでも原因が異なることがあるので、症状がはっきりしているときや長引くときは受診してください。
