Enter the distance you've actually been running over the past few weeks. A plan built on a sudden jump in distance becomes a plan for injury.

How the plan is built

  • Hard days (quality sessions and long runs) are separated by rest days or easy runs.
  • Quality volume per session stays within 10% of weekly distance for T, 8% for I and 20% for M.
  • Long runs stay under 150 minutes. Running only 3–4 days a week makes the long run a bigger share, so judge it by time rather than distance.
  • Below 20 km a week, build distance with easy runs before adding quality sessions.
  • The plan is a sample week. On days you feel heavy or sore, swapping a quality session for an easy run is following the plan.
